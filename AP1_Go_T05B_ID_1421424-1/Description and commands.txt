ЛОГИН Присвоить JWT в переменные
RESP=$(curl -s -X POST http://localhost:8080/signin \
  -H 'Content-Type: application/json' \
  -d '{"login":"valmerar3","password":"123456"}')

A=$(echo "$RESP" | jq -r '.accessToken')
AR=$(echo "$RESP" | jq -r '.refreshToken')

echo "A  = ${A:0:20}..."
echo "AR = ${AR:0:20}..."

Получить пользователя по токену
curl -s http://localhost:8080/user \
  -H "Authorization: Bearer $A"

Проверяем refresh access token

AA=$(curl -s -X POST http://localhost:8080/refresh-access-token \
  -H 'Content-Type: application/json' \
  -d "{\"refreshToken\":\"$AR\"}" | jq -r '.accessToken')

echo "AA = ${AA:0:20}..."

Получить историю игру игрока по JWT
curl -s http://localhost:8080/history \
  -H "Authorization: Bearer $A" | jq

Посмотреть leaderboard через игрока с JWT 
curl -i "http://localhost:8080/leaderboard?n=10" \
  -H "Authorization: Bearer $AA"

Проверяем refresh access token
curl -s -X POST http://localhost:8080/refresh-access-token \
  -H "Content-Type: application/json" \
  -d "{\"refreshToken\":\"$REFRESH_TOKEN\"}"
Причём refreshToken в этом ответе отсутствует — это соответствует реализации.

Проверяем refresh refresh token
